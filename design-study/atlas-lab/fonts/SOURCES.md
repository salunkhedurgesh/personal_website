# Local prototype fonts

Downloaded from the official Google Fonts CSS API / `fonts.gstatic.com` on 2026-09-18. All files are normal-style variable WOFF2 Latin subsets and are served locally by this prototype; no runtime font request is needed. The exact SIL Open Font License text for each family is included alongside the files.

The Latin subsets include common Western European accented letters. Additional character sets or italic fonts must be added if future content requires them. Use `font-optical-sizing: auto` for Inter and Newsreader.

|---|---|---|---:|---|
| Inter | `inter-latin-variable.woff2` | wght: 100–900; opsz: 14–32 | 72,920 | [inter-OFL.txt](inter-OFL.txt) |
