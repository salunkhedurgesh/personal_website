Chess analysis engines

The board checks Lichess cloud evaluation first. Lichess returns cached position analysis; a missing position does not start a new cloud search. Only the position (FEN) is sent.

If a cloud evaluation is missing, unavailable, or below depth 8, these five free, open-source engine builds calculate live in browser workers, in this order. The backups run on your device; they are not five independent cloud services. Every displayed engine score must have completed at least depth 8 with a legal principal variation.

  1. Stockfish 19 Lite, single-threaded WebAssembly — Stockfish.js 19.0.1, GPL-3.0. License.
  2. tomitankChess 7.0 — Tamas Kuzmics. Upstream revision, GPL-3.0-or-later. License; complete engine source.
  3. Lozza 11.0 — Colin Jenkins. Upstream release, permissive upstream license; complete engine source, including weights.
  4. Stockfish 19 ASM JavaScript — a compatibility build from the same Stockfish.js release, for browsers where WebAssembly fails. GPL-3.0; shares the Stockfish source and license above.
  5. Garbochess-JS — Gary Linscott. Upstream revision, BSD license; complete engine source and the site's UCI worker adapter.

Corresponding source for both Stockfish builds is provided in the original Stockfish.js 19.0.1 source archive, together with the exact embedded neural network. The archive includes authors, build scripts, Emscripten glue, and the GPL license. See its README for build instructions. Place the network in src/; use Emscripten 6.0.9 and node build.js --lite --single-threaded or node build.js --asm-js.

Positive scores favour White; negative scores favour Black. Scores from different engines can differ. The displayed depth is the engine's reported completed search depth, not a guarantee of perfect play. Checkmate and stalemate are shown directly when there are no legal moves.

Release URLs and SHA-256 checksums are recorded in the asset manifest.
